# 📊 Amazon Prime Video Dashboard | Power BI

An interactive Power BI dashboard built to analyze Amazon Prime Video content across genres, countries, ratings, release years, directors, and content types.

## 📌 Project Overview

This project analyzes Amazon Prime Video titles using Microsoft Power BI.

The dashboard provides an interactive view of the content library and allows users to explore Movies and TV Shows using filters and visualizations.

## 🎯 Project Objectives

- Analyze the total number of titles available
- Explore content across different genres
- Identify countries with the highest number of titles
- Analyze content ratings
- Compare Movies and TV Shows
- Analyze titles by release year
- Understand the distribution of content across countries
- Explore the number of directors and genres

## 📌 Key Insights

- The dataset contains 9,655 titles.
- Drama is the largest genre shown in the dashboard.
- Movies represent 80.82% of the content, while TV Shows represent 19.18%.
- The dashboard contains content spanning release years from 1920 to 2021.
- The dashboard allows comparison of content by ratings, countries, genres, and release years.
